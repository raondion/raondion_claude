# 인스타그램 릴스 편집·업로드 대행 — 매장 직원 교육안

> 서비스 구조: **촬영은 매장 직원**, **편집·업로드는 라온디온**.
> 가격은 [치악산한우 시장가격 조사](../치악산한우-혁신점/시장가격_및_가격제안.md)의 릴스 운영 하한선(월 25만원,
> 매장 촬영 + 라온디온 편집·업로드)을 기준으로 한다.
>
> 이 구조에서는 **직원이 보내주는 원본 영상의 질이 결과물의 질을 결정한다.**
> 그래서 교육의 목표는 "잘 찍는 사람 만들기"가 아니라 "편집하기 좋은 재료를 매일 꾸준히 보내게 하기"다.

---

## 1. 교육 방식

| 단계 | 방식 | 시간 |
|---|---|---|
| 첫 교육 | 매장 방문, 직원과 같이 직접 찍어보는 실습 | 1시간 |
| 촬영 가이드 | A4 한 장짜리 가이드를 라온디온이 인쇄해서 주방·카운터에 부착 | — |
| 첫 2주 피드백 | 보내준 영상마다 카톡으로 "좋아요 / 이렇게 바꿔주세요" 짧게 피드백 | 매일 |
| 정기 점검 | 한 달에 한 번, 반응 좋았던 릴스를 보여주며 다음 달 찍을 거리 정하기 | 20분 |

**A4 촬영 가이드를 인쇄해서 붙여주는 것** 자체가 라온디온 강점 — 다른 대행사는 카톡 공지로 끝낸다.

---

## 2. 교육 내용

### ① 촬영 기본 6가지 (A4 가이드 앞면)

1. **무조건 세로로** — 휴대폰을 세워서 찍기. 가로로 찍으면 릴스에 못 쓴다
2. **렌즈 닦기** — 주방 기름·손자국이 가장 흔한 실패 원인
3. **줌 대신 다가가기** — 확대하면 화질이 떨어진다. 기본 배율(1배)로 가까이 가서 찍기
4. **한 컷은 3~10초, 앞뒤로 1~2초 여유** — 찍기 시작하고 1초 기다렸다가 움직이기. 편집할 여유가 생긴다
5. **흔들리지 않게** — 양손으로 잡거나 팔꿈치를 몸이나 벽에 붙이기
6. **밝은 곳에서** — 창가 자연광이 가장 좋다. 창을 등지고 찍으면(역광) 얼굴·음식이 어둡게 나온다

### ② 매일 찍을 거리 (A4 가이드 뒷면 — 체크리스트)

업종에 맞게 매장마다 다르게 만든다. 고기집(치악산한우) 예시:

- [ ] 오픈 준비 — 불 켜는 장면, 테이블 세팅
- [ ] 고기 손질·진열 클로즈업
- [ ] 불판 위에서 굽는 장면 — **지글지글 소리가 핵심, 가까이서 소리까지**
- [ ] 한 상 차림을 위에서 내려다본 장면
- [ ] 계절 메뉴, 신메뉴, 오늘의 추천
- [ ] 사장님·직원의 짧은 인사 (본인이 동의한 경우만)
- [ ] 마감 후 매장 모습, 예약 많은 날의 분위기

하루 목표: **짧은 클립 3~5개**. 완벽한 한 편이 아니라 재료 여러 개를 보내면 라온디온이 이어 붙인다.

### ③ 소리

- 현장 소리(굽는 소리, 칼질, 주문 들어가는 소리)는 그대로 살려서 찍기 — 음식 릴스에서 가장 반응 좋은 요소
- 음악은 넣지 말고 보내기 — 음악은 라온디온이 넣는다
- 참고: 비즈니스 계정은 인스타그램 음악 중 상업적 사용이 허용된 곡만 쓸 수 있어서, 라온디온이 사용 가능한 음원으로 편집한다

### ④ 찍으면 안 되는 것 — 초상권·개인정보

- **손님 얼굴** — 동의 없이 찍지 않기. 손님이 나온 장면은 얼굴이 안 보이게 손·뒷모습만
- **아이 얼굴** — 부모 동의가 있어도 가급적 피하기
- **직원 얼굴** — 본인이 동의한 직원만
- 카드 결제 화면, 영수증, 예약 명단, 손님 휴대폰 화면, 차량 번호판

### ⑤ 영상 보내는 방법

- **원본 화질로 보내기** — 카톡은 "원본 전송" 또는 [공유 폴더 — 구글 드라이브, 네이버 MYBOX 등 매장과 정하기]
- 보낼 때 한 줄 메모 — "신메뉴 ○○", "이번 주 토요일 휴무" 처럼 무슨 영상인지
- 매일 [보내는 시간 — 예: 영업 마감 후]까지 보내기
- 휴대폰 카메라 설정: 1080p 또는 4K, 30fps (교육 때 직원 휴대폰에서 같이 맞춰준다)

### ⑥ 역할 나누기 — 누가 무엇을 하나

| 일 | 매장 | 라온디온 |
|---|---|---|
| 촬영, 영상 보내기 | ✔ | |
| 편집(자르기, 자막, 음악), 업로드 | | ✔ |
| 업로드 전 확인 | [사장님이 확인할지 — 매장과 정하기] | 미리보기 전달 |
| 댓글·DM 답변 | ✔ (편집·업로드만 대행하므로) | 답변이 필요한 댓글은 카톡으로 알려드림 |
| 월간 반응 정리 | | ✔ 조회수·저장·공유 상위 릴스 공유 |

### ⑦ 계정 관리

- 인스타그램 계정은 **매장 소유**. 비밀번호를 공유하지 않고, Meta 비즈니스 도구에서 라온디온을 관리자 권한으로 추가하는 방식으로 운영한다
- 2단계 인증은 사장님 휴대폰으로
- 계약이 끝나면 라온디온 권한만 빼면 된다 — 스마트플레이스 소유권 원칙과 같다

### ⑧ 자막·문구에서 조심할 것 (라온디온이 편집할 때 지키고, 사장님께도 안내)

- "최고", "1등", "원주에서 제일" 같은 근거 없는 최상급 표현은 표시광고법상 문제가 될 수 있다
- 효능 주장(예: "먹으면 건강해지는") 하지 않기
- 협찬·체험단 영상은 "협찬" 표시

---

## 3. 교육 후 체크 — 잘 되고 있는지 보는 기준

- 매일 클립이 들어오는가 (주 5일 이상)
- 세로 촬영, 렌즈, 흔들림 문제가 2주 안에 줄었는가
- 한 달에 올릴 릴스 개수만큼 재료가 모이는가 — [주 n회 업로드 기준, 릴스 1개에 클립 5~8개 필요]

재료가 안 모이면 편집·업로드 대행만으로는 운영이 어렵다 → 라온디온 방문 촬영 추가(치악산한우 가격표 상한 월 40만원 구간)를 제안한다.
