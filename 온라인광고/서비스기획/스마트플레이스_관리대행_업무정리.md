# 네이버 스마트플레이스 관리대행 — 업무 정리와 라온디온 차별점

> 다른 대행 업체들이 보통 무엇을 해주는지 정리하고, 라온디온 대표님 경력으로 더 잘할 수 있는 점을 제안한다.
> 가격은 [치악산한우 시장가격 조사](../치악산한우-혁신점/시장가격_및_가격제안.md) 기준: 기본 관리 월 10만원~,
> 광고 운영 포함 월 30만원~ / 라온디온 제안가 월 15~20만원 (순수 관리).

---

## 1. 대행 업체들이 주로 하는 업무

### ① 처음 세팅 (계약 첫 달)

| 업무 | 내용 |
|---|---|
| 소유자 인증·관리자 위임 | 사장님 명의로 소유자 인증 후, 대행사를 관리자로 추가 |
| 기본 정보 정리 | 업체명, 업종 카테고리, 주소·길찾기, 주차, 영업시간·휴무일·브레이크타임, 전화번호 |
| 대표 키워드 | 손님이 검색할 만한 키워드 5개 선정 (예: "원주 한우", "혁신도시 고기집") |
| 소개글 | 매장 설명을 검색에 걸리는 문장으로 작성 |
| 메뉴·가격 | 메뉴 이름, 가격, 메뉴 사진 등록 |
| 사진 정리 | 대표 사진 선정, 외관·내부·메뉴 사진 순서 정리 |
| 편의 기능 연결 | 예약, 네이버 톡톡, 쿠폰, 편의시설(주차·단체석·포장 등) 표시 |

### ② 매달 하는 관리

| 업무 | 내용 |
|---|---|
| 리뷰 답글 | 방문자 리뷰·블로그 리뷰에 답글. 불만 리뷰는 사장님과 상의해서 대응 |
| 소식 등록 | 신메뉴, 이벤트, 휴무, 계절 메뉴 소식을 주 1~2회 올림 |
| 정보 최신화 | 가격 변경, 임시 휴무, 메뉴 추가를 바로 반영 |
| 사진 추가 | 계절·신메뉴 사진을 주기적으로 교체 |
| 리뷰 유도 | 매장 안내문, 영수증 리뷰 안내 등으로 실제 손님 리뷰를 늘림 |
| 월간 리포트 | 조회수, 유입 키워드, 길찾기·전화·예약 수를 정리해 보고 |

### ③ 추가 비용을 받는 업무

| 업무 | 내용 |
|---|---|
| 플레이스 광고 운영 | 네이버 광고시스템에서 키워드·예산 설정. 광고비는 사장님 계정에서 별도 결제 |
| 블로그 체험단 | 체험단 모집·선정·관리. 제공한 식사 등은 "협찬" 표시 필수 |
| 사진 촬영 | 전문 촬영 기사 방문 촬영 |

### ④ 시장에 있지만 라온디온은 하지 않는 것

치악산한우 제안서 검토 때 확인한 것처럼, 일부 업체는 아래 방식을 팔고 있다.
네이버 정책 위반이거나 표시광고법 위반 소지가 있어 라온디온은 하지 않는다 — 이것 자체가 차별점이 된다.

- 방문하지 않은 사람의 리뷰를 건당 돈을 받고 써주는 "리뷰 구매"
- "1~3페이지 순위 보장" 같은 정액 광고 (매크로 트래픽이거나, 평범한 광고를 비싸게 되파는 구조일 가능성)
- 저장·클릭 수를 인위적으로 올리는 트래픽 작업
- 대행사 명의로 소유권이나 광고 계정을 가져가는 것

## 2. 라온디온이 더 잘할 수 있는 것 — 내세울 점 제안

대표님 경력: 디자인·인쇄 25년(그중 12년 LA 인쇄소 팀장), 라스베가스 판촉물 박람회(PPAI) 3년 참가,
직접 디자인, 업종별 소재 지식, 소량 제작 장비 보유, 빠른 카톡 응답, 블로그 관리 경험(송파 케이투수학학원), 원주 소재.

### ① "사진과 이미지를 디자이너가 직접 만듭니다"

- 대부분의 대행사는 사장님이 보내준 사진을 그대로 올리거나 템플릿 이미지를 쓴다.
- 라온디온은 대표 사진 보정, **메뉴판 이미지 디자인**, 소식용 이벤트 이미지를 직접 디자인한다.
- 플레이스에서 손님이 가장 오래 보는 건 사진과 메뉴판 — 여기서 25년 디자인 경력이 바로 보인다.
- 제안 문구: "플레이스에 올라가는 모든 이미지를 디자이너가 직접 만듭니다."

### ② "온라인과 매장을 같이 챙깁니다" — 인쇄물까지 한 번에

다른 대행사는 온라인만 관리하지만, 라온디온은 매장에 붙일 인쇄물을 직접 만들 수 있다.

- 리뷰 안내 테이블 POP, 계산대 안내문
- "네이버에서 ○○○ 검색" 문구를 넣은 배너·현수막·명함
- 저장·알림받기를 안내하는 QR 스티커 (UV스티커로 테이블·유리문에)
- 플레이스 메뉴판과 매장 메뉴판을 같은 디자인으로 통일
- 제안 문구: "온라인 관리부터 매장 안내물까지, 한 곳에서."
- 주의: 리뷰를 쓰는 조건으로 대가를 주는 이벤트는 대가 제공 사실을 표시해야 하고 네이버 정책에도 걸릴 수 있으니, 안내물은 "리뷰 부탁드려요" 수준의 안내나 저장·알림받기 이벤트 위주로 설계한다.

### ③ "판촉물 전문가가 이벤트를 기획합니다"

- 라스베가스 판촉물 박람회 3년 경험 — 증정품·판촉물을 보는 눈은 일반 마케팅 대행사가 따라올 수 없다.
- 소식에 올리는 이벤트(오픈 기념, 재방문, 단체 손님 등)에 맞는 **증정품을 기획하고 소량 직접 제작** (브랜딩 스티커, 컵 스티커 등).
- 제안 문구: "소식만 올리는 게 아니라, 손님이 받아갈 선물까지 만들어드립니다."

### ④ "원주 매장에 직접 갑니다"

- 전국 대행사는 전화·원격으로만 관리한다.
- 라온디온은 원주에 있어서 매장에 직접 와서 정보를 확인하고, 사진을 찍고, 사장님과 얼굴 보고 상의할 수 있다.
- 제안 문구: "원주 사장님 곁에 있는 대행사."

### ⑤ "순위 보장·리뷰 구매는 하지 않습니다" — 정직한 운영

- 치악산한우 제안서 검토처럼, 사장님이 받은 다른 업체 제안서를 **먼저 무료로 검토해드리는 것**으로 상담을 시작할 수 있다.
- 소유권·광고 계정은 항상 사장님 명의. 계약서(`양식/온라인마케팅_대행계약서.md`) 제5·6조에 이미 명시.
- 제안 문구: "사장님 가게 계정은 사장님 것입니다. 순위를 사고팔지 않습니다."

### ⑥ "간판부터 플레이스까지 같은 얼굴로" — 브랜딩과 연결

- 간판, 명함, 메뉴판, 포장, 플레이스 사진이 제각각인 매장이 많다.
- 라온디온 브랜딩 컨설팅(필요한 제품 최대 5가지 추천, 10~50개 테스트 제작)과 묶어서, 플레이스 관리를 브랜딩의 첫 단계로 제안한다.

### ⑦ "카톡 한 줄이면 당일 반영"

- 임시 휴무, 가격 변경, 품절 메뉴를 카톡으로 보내주시면 바로 반영 — 빠른 응답은 대표님이 손님들께 이미 인정받는 강점.

---

## 3. 제안서에 쓸 한 줄 요약 (예시)

> **디자이너가 직접 관리하는 원주 스마트플레이스.**
> 사진·메뉴판 디자인부터 매장 안내물 제작까지, 순위 장사 없이 정직하게.
