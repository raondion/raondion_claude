# 테마 판스티커 (라온디온 자체제작) 상세페이지 흐름도

> 라온디온이 직접 디자인한 기성품 UV 투명스티커. 100×130mm, 한 장 4,000원.
> 캔버스액자 흐름도와 같은 기승전결 순서. A~E는 [UV스티커_공통정보.md](UV스티커_공통정보.md)의 섹션을 그대로 쓴다.
> 기성품이라 맞춤 제작 과정(사진 보내기, 시안 확인)이 없다 — 흐름이 다른 두 상품보다 짧다.

## 판매 구성

| 테마 | 구성 | 가격 |
|---|---|---|
| 계절 꽃과 잎 | 계절을 대표하는 꽃과 잎 | 4,000원 |
| 반려동물 — 강아지 | 3종 | 4,000원 |
| 반려동물 — 고양이 | 3종 | 4,000원 |
| 내동생 | 남자 어린이 / 여자 어린이 | 4,000원 |
| (추가 예정) 나라별 여행 | 나라별 여행 스티커 | 4,000원 |

- 크기: 100×130mm
- **판매 단위: 세트가 아니라 디자인마다 한 장씩** — 옵션 하나 = 판스티커 한 장
- 테마별 세부 디자인(계절·종류, 한 장에 들어가는 스티커 개수)은 대표님이 디자인한 뒤 예시로 채운다: [디자인 후 입력]
- 옵션명은 스마트스토어 옵션 선택창과 이 표를 똑같이 맞춘다. 여행 테마는 추가될 때 옵션만 늘리면 되게, 5번 섹션을 테마별 블록으로 만든다.
## 전체 흐름

```
[기] 1. 첫 화면 — 붙이는 순간, 특별해지는 일상
     2. 공감 — 다 똑같아 보이는 내 물건
[승] 3. 제품 소개 — 붙이기만 하면 되는 투명 UV스티커
     4. 테마 한눈에 보기
     5. 테마별 소개 (계절 꽃과 잎 / 강아지 / 고양이 / 내동생 / 여행 예정)
     6. 이런 곳에 붙여요
[전] 7. 라온디온이라서 다른 점
     8. 붙이는 방법 (공통 A)
     9. 물로 씻어도 괜찮아요 (공통 B)
    10. 제품 정보 (공통 C)
[결] 11. 배송 & 수령 (공통 D)
    12. 꼭 확인해주세요 — 기성품 교환·환불
    13. 마무리 (공통 E)
```

## 섹션별 구성

### [기] 1. 첫 화면

- **카피** (첫화면 UV스티커 배너와 통일)
  - 보조 카피(얇게): 붙이는 순간, 특별해지는 일상
  - 헤드라인(네이비, 굵게): 평범한 상품도, 당신만의 특별한 이야기로
  - 설명(검정, 얇게): 투명해서 더 특별한 UV스티커. 한 장 4,000원.
- **이미지**: `UV스티커_상세이미지.png` (텀블러·머그컵·폰케이스 연출)

### [기] 2. 공감 — 다 똑같아 보이는 내 물건

- **카피**
  - 매일 쓰는 텀블러, 폰케이스, 다이어리. 다른 사람 것과 구분되나요?
  - 스티커 몇 장이면 내 취향이 담긴 물건이 됩니다.
- **이미지**: 스티커 붙이기 전 / 후 텀블러 비교

### [승] 3. 제품 소개

- **카피**
  - 배경 없이 그림만 남는 UV 투명스티커예요.
  - 한 장에 여러 개가 들어 있어서, 마음에 드는 것만 골라 붙이면 돼요.
  - 세트로 묶지 않고 한 장씩 팔아요. 마음에 드는 디자인만 골라 담으세요.
  - 라온디온이 직접 그리고 디자인한 테마만 모았어요.
- **이미지**: 판스티커 한 장 전체 + 한 개를 떼어 붙이는 손

### [승] 4. 테마 한눈에 보기

- **목적**: 스크롤을 내리기 전에 전체 테마를 한 화면에서 보고 고르게 한다.
- **구성**: 테마별 판스티커를 작게 나란히 (계절 꽃과 잎 / 강아지 3 / 고양이 3 / 내동생 2) + "나라별 여행 스티커 곧 나와요"
- **디자인 메모**: 테마 이름은 검정 얇게, 번호는 옵션 번호와 같게

### [승] 5. 테마별 소개

테마마다 같은 구성의 블록으로 만든다 (새 테마를 추가할 때 블록만 하나 더 붙이면 되게).

- **블록 구성**: 테마 이름 → 판스티커 한 장 크게 → 한 줄 카피 → 붙인 예시 사진 1컷
- **계절 꽃과 잎** — 계절을 내 물건에 [디자인 후 계절·꽃 이름과 카피 입력]
- **강아지 (3종)** — [디자인 후 종류별 한 줄 카피 입력]
- **고양이 (3종)** — [디자인 후 종류별 한 줄 카피 입력]
- **내동생 (남자·여자 어린이)** — 귀여운 우리 동생을 스티커로
- **나라별 여행 (추가 예정)** — 추가될 때 블록을 새로 만든다

### [승] 6. 이런 곳에 붙여요

- 투명 폰케이스, 실리콘 케이스
- 텀블러, 유리컵, 물병 (식기세척기 OK)
- 노트북, 태블릿, 가죽 다이어리
- **이미지**: 장면별 사진 3~4컷

### [전] 7. 라온디온이라서 다른 점

- 25년 동안 디자인부터 인쇄까지 직접 해온 라온디온이 한 장 한 장 직접 디자인했어요.
- 어디서나 파는 스티커가 아니라, 라온디온에서만 만날 수 있는 테마예요.

### [전] 8~10. 붙이는 방법 / 물로 씻어도 괜찮아요 / 제품 정보

- 공통정보 **A, B, C** 그대로 사용. C의 크기는 "100×130mm"

### [결] 11. 배송 & 수령

- 공통정보 **D** 그대로 사용

### [결] 12. 꼭 확인해주세요

- 공통정보 "교환·환불 기준"의 **테마 판스티커(기성품)** + **공통** 문구

### [결] 13. 마무리

- 공통정보 **E** 그대로 사용
- 추가: 우리 아이 얼굴로 만드는 포토 판스티커, 우리 가게 로고로 만드는 브랜딩 판스티커도 있어요 (두 상품 링크)

## 필요한 이미지

- 테마별 판스티커 실물 사진 (새 테마로 제작 후)
- 테마별 붙인 예시 사진
- 붙이기 전 / 후 비교 사진
