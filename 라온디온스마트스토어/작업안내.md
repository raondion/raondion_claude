# 라온디온 스마트스토어 작업 폴더

## 첫 화면 프로모션 이미지

- 최종 크기: 1920 × 400 px
- 기본 구성: 제품 이미지는 오른쪽, 왼쪽은 문구 작업용 여백
- 연결 방식: 오른쪽 이미지에서 왼쪽 여백으로 부드러운 밝은 그라데이션
- 파일 형식: PNG

## 폴더 구분

- `01_캔버스액자`: 여행 사진 캔버스 제품 이미지
- `02_UV스티커`: 사업자·개인용 맞춤 UV 스티커 이미지
- `03_브랜딩`: 컵, 명함, 스티커, 헤더택, 패키지 브랜딩 이미지

각 폴더의 `원본_생성본.png`는 후속 편집용이며, `프로모션_1920x400.png`가 스마트스토어 업로드용 최종 규격 파일입니다.
