## 1. 문제 인식 (Problem)

### 1-1. 창업 배경

25년 동안 디자인과 인쇄 현장에서 일하며 같은 장면을 반복해서 봤습니다.

- 처음 가게를 여는 사장님은 **"무엇을 만들어야 하는지"부터 막막**해합니다. 하고 싶은 것과 꼭 해야 하는 것이 구분되지 않아, 필요 없는 인쇄물에 돈을 쓰거나 꼭 필요한 것을 빠뜨립니다.
- 신제품을 준비하는 사장님은 **검증되지 않은 제품에 대량 패키지를 주문하기가 부담**스럽습니다. 박스·쇼핑백·스티커는 최소 주문 수량이 커서 처음부터 수백 개를 만들고, 제품이 바뀌면 남은 재고는 버려집니다.
- 디자이너와 인쇄소 입장에서는 소량 시제품이 **수익으로 이어지지 않아** 거절하거나 미루게 됩니다. 그래서 정작 가장 도움이 필요한 첫 단계의 사장님이 도움을 받기 어렵습니다.

이 공백을 직접 해결해 보고 싶다는 생각에서 이 사업을 시작했습니다.

## 2. 실현 가능성 (Solution)

### 2-1. 서비스 내용

고객의 상황에 따라 두 갈래로 나눕니다.

**① 첫 브랜딩 소량 제작** — 로고·매장 분위기가 아직 정해지지 않은 예비·초기 창업자

| 단계 | 내용 |
|---|---|
| 1. 아이디어 듣기 | 손그림, 참고 이미지, 말로 하는 설명만 있어도 시작 |
| 2. 디자인 상담 | 업종별 "꼭 필요한 첫 인쇄물"을 정리하고 실제 제작 사례로 비교 |
| 3. 인쇄용 데이터 | 인쇄 가능한 벡터·AI 파일 제작 (고객 소유) |
| 4. 구조·칼선 | 패키지 구조와 칼선 설계 |
| 5. 실물 시제품 | 10개 안팎의 실물 시제품 제작 |

**② 신제품 소량 제작** — 로고와 매장 분위기는 있고, 신제품 패키지가 필요한 1~3년 차 사장님

| 단계 | 내용 |
|---|---|
| 1. 품목 결정 | 패키지로 만들 품목을 5가지 이내로 함께 결정 |
| 2. 디자인 상담·데이터 | 디자인 상담 후 인쇄용 벡터·AI 파일 |
| 3. 구조·칼선 | 품목별 구조·칼선 설계 |
| 4. 시제품 | 품목별 10개 미만 실물 시제품 |
| 5. 추가 소량 제작 | 원하면 시제품을 수정해 50~100개 소량 제작 → 이후 대량 인쇄 연결 |
