## 2. 심사위원(책임멘토)이 보는 5가지

| # | 심사위원의 질문 | 통과하는 답 | 떨어지는 답 |
|---|---|---|---|
| 1 | **무엇이 달라졌나?** | "신청서 때는 A였는데, 설문·인터뷰 결과 B로 바꿨다" | 신청서 내용을 표현만 바꿔 다시 제출 |
| 2 | **고객이 정말 원하나?** | 응답자 n명, 인터뷰 기록, 실제 사장님 인용 | "사장님들이 불편해한다"는 주장만 있음 |
| 3 | **실제로 만들어 봤나?** | 시제품 사진, 제작 비용·시간, 고객 반응 | 계획만 있고 결과물 없음 |
| 4 | **지원금을 잘 썼나?** | 지출마다 남은 결과물이 있음 | 아이템과 관계없는 지출, 증빙 누락 |
| 5 | **멘토링을 활용했나?** | 조언 → 반영 → 결과를 보고 | 출석만 함 |

## 3. 핵심 서사 — 신청서 대비 무엇이 고도화되었나

심사위원에게 가장 강하게 보여줄 표입니다. 사업계획서 앞부분 또는 활동 보고서에 넣으세요.

| 항목 | 1R 신청서 | 2R 사업계획서 (현재) | 바뀐 근거 |
|---|---|---|---|
| **목표 고객** | 첫 창업 및 1~3년 차 사장님 (카페·공방·답례품·굿즈·음식점·밀키트) | 원주·횡성의 **소형 카페, 온라인몰, 빵카페, 공방** (B2B) — **빵카페 우선 공략** | 3C 분석: 빵카페는 대체재(온라인 인쇄몰)가 약하고 주문 금액이 큼 / 설문 업종별 응답 [ ] |
| **고객 문제** | 여러 업체 연락의 번거로움, 대량 패키징의 비용·재고 부담 | 3가지로 구조화: ① 검증 전 대량 투자 ② 흩어진 공급 구조 ③ **판단 기준 부재(식품 표시사항 등)** | 고객여정지도 분석, 설문 Q6 결과 [ ] — **③은 신청서에 없던 새 발견** |
| **경쟁 인식** | 언급 없음 | 지역 간판·실사 업체와는 **협력 관계**, 실제 경쟁은 온라인 인쇄몰 | 지역 업체 조사, 인쇄몰 최소 수량 비교 [ ] |
| **차별점** | 원스톱, 1개부터 | + **식품 표시사항 체크리스트**, 고객별 파일 보관 재주문 | 페인포인트 ③ 대응 |
| **수익 구조** | 2개 카테고리, 기본 금액 + 추가 비용 | 세트 상품(A·B·C) + 대량 연결 + 재주문 | 설문 지불 의향 [ ]만 원대 |
| **검증** | 설문 계획 | 설문 [ ]명, 인터뷰 [ ]명, 시제품 [ ]건 | 1R 활동 결과 |

## 4. 문서별 — 심사위원 관점 수정 팁

### 공통 원칙
- **첫 장에 요약 1장**: 심사위원은 수십~수백 건을 봅니다. 문제–해결–검증 결과–목표를 한 장에 넣으세요.
- **"주장 + 근거"를 한 세트로**: 모든 숫자에 출처와 기준 연도를 붙입니다.
- **[추정]은 본문에서 줄이기**: 분석 문서에는 남겨 두되, 제출 문서에는 **확인된 내용 위주**로 씁니다. 확인 못 한 부분은 "검증 계획"으로 바꿔 씁니다.
- **약점을 숨기지 않기**: 1인 기업이라는 약점은 심사위원이 먼저 봅니다. 대응책과 함께 쓰면 오히려 신뢰가 생깁니다.
- **가상 자료 표시**: AI로 만든 가상 홈페이지의 사례·후기는 실제처럼 쓰지 말고 "서비스 구상 화면(가상)"으로 표시하거나 빼세요.

### ① PEST 분석
| 지금 | 이렇게 고치면 좋음 |
|---|---|
| 4개 영역 × 여러 항목의 긴 분석 | 사업계획서에는 **우리 사업과 직접 연결된 4~5개 지표**만 표 1개로 압축 (생존율 39.6%, 창업비용 8,300만 원, 온라인쇼핑 272조 원, 디지털 인쇄 성장) |
| 과대포장 규제 등 영향이 약한 항목 포함 | 영향이 약한 항목은 빼기 — 심사위원은 "왜 이게 우리 사업과 관련 있나"를 봄 |

### ② 3C 분석
| 지금 | 이렇게 고치면 좋음 |
|---|---|
| 경쟁사 실명 표기 | 제출 문서에서는 **"지역 간판·실사 업체 A, B"**로 익명 처리. 경쟁사를 깎아내리는 표현은 감점 요인 |
| 경쟁사 비교표에 [확인] 칸 다수 | 견적 문의로 채우거나, 채우지 못한 항목은 표에서 빼기 |
| 대체재(온라인 인쇄몰) 비교가 정성적 | **수치 비교표**로: 최소 수량, 단가, 디자인 포함 여부, 실물 확인 가능 여부 (3곳 이상) |

### ③ SWOT 분석
| 지금 | 이렇게 고치면 좋음 |
|---|---|
| 교차 전략이 많음 (SO·ST·WO·WT 각 4~5개) | 사업계획서에는 **우선순위 상위 3개 전략만** — 이 3개가 Solution·Scale-up 계획과 정확히 일치해야 함 |
| 약점 W1(1인 운영) | "협력 인쇄소 [ ]곳 확보", "세트 표준화로 건당 작업 시간 [ ]시간 → [ ]시간"처럼 **실행 결과**로 보여주기 |

### ④ 고객여정지도
| 지금 | 이렇게 고치면 좋음 |
|---|---|
| 가상 페르소나 | **실제 인터뷰한 빵카페 사장님 1명의 사례**로 교체 (동의 후 익명). 가장 큰 가점 요소 |
| 고객 생각·감정이 추정 | 인터뷰에서 들은 **실제 말**로 바꾸기 |
| 라온디온 대응 = 계획 | 1R 기간에 실제로 해본 단계(상담 → 시제품)는 "실행함"으로 표시하고 사진 첨부 |

### ⑤ P(문제 인식) · 페인포인트
| 지금 | 이렇게 고치면 좋음 |
|---|---|
| 설문 수치 `[ ]` | 반드시 채우기. **"응답자 n명 중 x%"**처럼 표본 수를 함께 적기 |
| 기존 고객 응답 포함 | 기존 고객과 신규 응답을 나눠 제시 — 심사위원의 "편향 아니냐" 질문을 미리 차단 |
| 인용문 자리만 있음 | 사장님 인용 2~3개 (업종·지역·창업 연차 표시) |
| 문제 3(판단 기준 부재) | **신청서에 없던 새 발견**임을 명시 — "1R 고객 조사로 새로 확인한 문제"는 고도화의 직접 증거 |

### ⑥ 설문·인터뷰
