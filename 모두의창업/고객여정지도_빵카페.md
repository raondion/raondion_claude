## 3. 감정 곡선

```
 +2 |                          ● 기대                          ● 신뢰
 +1 |              ● 안심                   ● 만족
  0 |─────────────────────────────────────────────────────────────────
 -1 | ● 막막함
 -2 |        ● 불안
    └──────┬──────┬──────┬──────┬──────┬──────
         니즈   탐색   상담   시제품  본주문  재주문
```

- **가장 낮은 지점은 ② 탐색 단계**입니다. 업체를 여러 곳 비교해야 하고, 어디에 맡겨야 할지 모르는 시점입니다. → 이 단계에서 라온디온이 발견되도록 하는 것이 마케팅의 핵심입니다.
- **가장 크게 오르는 지점은 ④ 시제품 단계**입니다. 실물을 손에 쥐는 순간 불안이 기대로 바뀝니다. → 서비스의 핵심 가치가 드러나는 순간입니다.

## 4. 결정적 순간 (Moments of Truth)

| 순간 | 고객이 판단하는 것 | 라온디온이 지킬 기준 |

| **명절 전 납품** | "다음에도 여기에 맡기자" | 마감일 사전 공지, 납기 약속 준수 |

## 5. 핵심 페인포인트 3가지

여정 6단계의 불편 사항을 원인별로 묶으면 세 가지로 정리됩니다.

| | 페인포인트 ① 검증 전에 대량 투자 | 페인포인트 ② 흩어진 공급 구조 | 페인포인트 ③ 판단 기준 부족 |
|---|---|---|---|
| **한 줄 정의** | 팔릴지 모르는 제품에 포장을 먼저 대량으로 주문해야 함 | 디자인·인쇄·포장을 각각 다른 곳에 맡기고 매번 다시 설명해야 함 | 무엇을, 어떤 소재로, 어떤 규정에 맞춰 만들지 스스로 판단해야 함 |
| **발생 단계** | ① 니즈 발생, ⑤ 본 주문 (수량 결정) | ② 탐색, ⑥ 재주문 | ③ 상담·견적, ④ 시제품 |
| **고객 목소리** | "박스가 500개부터네… 다 못 팔면 어떡하지?" | "디자인 따로, 박스 따로 맡겨야 하나?" | "라벨에 뭘 넣어야 하는지 모르겠다" |
| **원인** | 박스·쇼핑백·특수 스티커의 최소 주문 수량, 소량 주문 시 높은 단가 | 업체마다 취급 품목이 다름, 디자인 파일을 고객이 준비해야 함, 주문 이력이 관리되지 않음 | 식품 표시사항 규정, 물·기름에 강한 소재 등 전문 지식이 필요하지만 상담해 주는 곳이 없음, 화면과 실물의 차이 |
| **고객이 잃는 것** | **돈** — 남는 재고, 디자인 변경 시 폐기 | **시간** — 1~2인 매장에서 여러 업체 응대·색상 맞추기 | **확신** — 잘못 만들까 봐 결정을 미루거나, 규정 누락 위험 |
| **심각도** | 높음 (비용 직결) | 중간 (반복적으로 발생) | 높음 (빵카페는 법정 표시 의무) |
| **검증 방법 (설문)** | Q6 "최소 주문 수량이 너무 많다", "남는 재고가 걱정된다" / Q9 원하는 수량 | Q6 "여러 업체에 따로 연락해야 해서 번거롭다" / Q7 연락한 업체 수 | Q6 "무엇을 만들어야 할지 모르겠다", "실물을 미리 볼 수 없다" / Q8 시제품 이용 의향 |
| **라온디온 해결 방향** | 1개~10세트 실물 시제품 → 판매 반응 확인 후 수량 확대, 100개 이상은 협력 인쇄소 연결 | 디자인부터 라벨·스티커·박스까지 한 곳에서, 고객별 파일·사양 보관으로 카카오톡 재주문 | 업종별 필요 품목 최대 5가지 추천, 식품 표시사항 체크리스트, 소재 상담, 실물 확인 후 결정 |

**우선순위**: ①과 ③은 비용과 규정에 직결되어 심각도가 높고, ②는 재주문 때마다 반복되어 장기 거래(B2B 반복 매출)와 연결됩니다.

## 6. 사업계획서 활용

- **P(문제 인식)**: ①~② 단계의 불편 사항이 "고객이 겪는 4가지 문제"의 실제 장면입니다.
- **S(실현 가능성)**: ③~⑤ 단계의 라온디온 대응이 서비스 프로세스입니다.
- **S(성장 전략)**: ⑥ 단계의 재주문·소개 구조가 B2B 반복 매출의 근거입니다. 성과 지표는 마케팅 목표로 사용합니다.
