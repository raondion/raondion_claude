# 네이버폼 설문지 — 라온디온 소량 패키지 제작 수요 조사

> `설문지_초안.md`를 네이버폼에 옮겨 넣을 수 있도록 항목 유형과 설정까지 정리했습니다.
> 진행 방식: **기존 고객**(카카오톡으로 링크 전송)과 **매장 직접 방문**(사장님 휴대폰으로 QR 스캔, 또는 태블릿으로 응답)
> 연락처 수집과 쿠폰 안내는 넣지 않았습니다. 개인정보를 받지 않기 때문에 개인정보 수집 동의 항목도 필요 없습니다.

---

## 폼 만들기 전 설정

| 설정 | 값 |
|---|---|
| 폼 제목 | 처음 창업하시는 사장님께 필요한 인쇄물·패키지 설문 |
| 테마 색상 | 다크 네이비 계열, 배경은 흰색 (라온디온 브랜드 색상) |
| 응답 설정 | 로그인 없이도 응답할 수 있는지 확인 (방문 설문 때 사장님이 로그인하느라 멈추지 않도록) |
| 응답 수정 | 허용 안 함 |
| 응답 결과 공개 | 공개 안 함 |
| 공유 | 링크 복사 → 카카오톡 전송용 / QR코드 → A5 안내지에 인쇄해 방문 때 지참 |

## 폼 A — 사장님·예비창업자용 (15문항, 약 3분)

### 폼 설명 (첫 화면)

```

처음 창업하시는 사장님들이 명함·스티커·패키지를
적은 수량부터 만들어볼 수 있는 서비스를 준비하고 있습니다.

사장님들께 실제로 필요한 것이 무엇인지 듣고 싶어 설문을 드립니다.
이름이나 연락처는 묻지 않으며, 응답은 서비스 준비에만 사용합니다.

약 3분 걸립니다. 감사합니다.
```

### 섹션 4. 마무리

**Q14.** 패키지나 인쇄물 때문에 겪으셨던 일을 자유롭게 들려주세요.
- 유형: **주관식 (장문형)** · **선택**
- 안내 문구: `예) 최소 수량 때문에 박스 500개를 주문했는데 절반이 남았어요`

**Q15.** 라온디온에 인쇄나 디자인을 맡겨보신 적이 있나요?
- 유형: **객관식 (1개 선택)** · 필수
```
네, 맡겨본 적 있어요
아니요, 처음이에요
```
> 추가 제안 문항입니다. 기존 고객 응답이 많으면 결과가 라온디온에 우호적으로 기울 수 있습니다. 이 문항으로 기존 고객과 처음 응답한 분을 나눠 볼 수 있으면, 심사위원이 편향을 물어볼 때 답할 수 있습니다. 필요 없으면 지우셔도 됩니다.

## 초안에서 바꾼 점

1. **Q2, Q11 구간 경계를 정리했습니다.** "1~3년 / 3년 이상", "5~7만 원 / 7~10만 원"처럼 경계값이 두 보기에 겹치던 것을 "이상 ~ 미만"으로 나눴습니다. 7만 원을 생각하는 분이 어느 쪽을 골라야 할지 헷갈리지 않습니다.
2. **Q9 "100개 이상"을 "101개 이상"으로** 바꿔 "51~100개"와 겹치지 않게 했습니다.
3. **Q10 보기를 실제로 풀어 썼습니다.** 초안의 "4번과 같은 보기"는 폼에서는 다시 입력해야 하고, 시제품 문항이라 "아직 없음"은 뺐습니다.
4. **Q4·Q5의 "없음"을 "아직 없음 / 아직 만든 적 없음"으로** 바꿨습니다. 창업 준비 중인 분이 자연스럽게 고를 수 있습니다.
5. **Q15를 추가 제안했습니다** (위 설명 참고).

## 방문 설문 때 팁

- QR 안내지를 A5로 뽑아 가시면, 사장님이 바쁠 때 "나중에 해주세요" 하고 두고 올 수 있습니다.
- 바로 응답받을 때는 질문을 읽어드리기보다 휴대폰을 건네드리는 편이 응답이 솔직합니다.
- 응답 마감 후 네이버폼 **결과 → 엑셀 다운로드**로 받으면 `설문지_초안.md` 아래의 "결과 정리할 때 만들 차트" 6개를 바로 만들 수 있습니다.
