# 설문지 초안 — 라온디온 소량 패키지 제작 수요 조사

> 네이버폼이나 구글폼에 그대로 옮겨 쓸 수 있게 정리했습니다. 3분 안에 끝나는 분량입니다.
> A형은 사장님·예비창업자용, D형은 타 지역 디자이너·인쇄소용입니다.

## A형 — 사장님·예비창업자용 (15문항)

**폼 첫 화면 안내문**

> 안녕하세요, 원주에서 25년째 디자인과 인쇄를 하고 있는 라온디온입니다.
> 처음 창업하시는 사장님들이 명함·스티커·패키지를 적은 수량부터 만들어볼 수 있는 서비스를 준비하고 있습니다.
> 사장님들께 실제로 필요한 것을 알고 싶어 설문을 드립니다. (약 3분)

### 1. 기본 정보

**1. 어떤 업종을 운영하시나요? (준비 중이신 업종도 괜찮습니다)**

**2. 창업하신 지 얼마나 되셨나요?**
- 준비 중 / 1년 미만 / 1~3년 / 3년 이상

**3. 사업장은 어디에 있나요?**
- 원주 / 횡성 / 그 밖의 강원 지역 / 강원 외 지역 / 매장 없음(온라인·플리마켓)

### 2. 지금의 인쇄물·패키지

**4. 현재 사용하고 계시거나 필요한 것을 모두 골라주세요. (복수 선택)**
- 명함 / 로고 스티커 / 제품 라벨 / 포장 박스 / 쇼핑백 / 헤더택·택 / 포장지·띠지 / 메뉴판 / 쿠폰·리플렛 / 현수막·배너 / 없음

**5. 지금은 주로 어떻게 만드시나요?**
- 온라인 인쇄몰 / 동네 인쇄소 / 지인 디자이너 / 직접 만듦(프린터·도장 등) / 기성품만 사용 / 아직 없음

**6. 인쇄물·패키지를 만들 때 가장 어려운 점은 무엇인가요? (최대 2개)**
- 최소 주문 수량이 너무 많다 / 처음 비용이 부담된다 / 남는 재고가 걱정된다 / 무엇을 만들어야 할지 모르겠다 / 디자인 파일이 없다 / 여러 업체에 따로 연락해야 해서 번거롭다 / 실물을 미리 볼 수 없다 / 기타(　　)

**7. 인쇄물을 만들 때 연락한 업체는 보통 몇 곳이었나요?**
- 1곳 / 2~3곳 / 4곳 이상 / 아직 만들어본 적 없음

### 3. 이런 서비스가 있다면

**8. 대량으로 주문하기 전에 실물 시제품을 먼저 받아볼 수 있다면 이용하시겠어요?**
- 꼭 이용하겠다 / 가격이 맞으면 이용하겠다 / 잘 모르겠다 / 이용하지 않겠다

**10. 시제품으로 가장 먼저 만들어보고 싶은 품목은 무엇인가요? (최대 3개)**

**11. 첫 브랜딩 세트(명함 + 로고 스티커 + 간단한 패키지 시제품, 디자인 포함)에 낼 수 있는 금액은 어느 정도인가요?**

**12. 이 서비스를 고를 때 가장 중요한 것은 무엇인가요? (1개)**

**13. 상담은 어떤 방식이 편하신가요?**
- 매장에 직접 방문 / 카카오톡 / 전화 / 화상 / 상관없음

## D형 — 타 지역 디자이너·인쇄소용 (6문항)

**안내문**

> 원주에서 1인 디자인·인쇄 공방을 운영하는 라온디온입니다.
> 소상공인 대상 "1개부터 시제품 패키지 제작" 방식을 다른 지역 디자이너·인쇄소와 나누는 방안을 검토하고 있습니다. (약 2분)

1. 어떤 형태로 일하시나요? — 1인 디자이너 / 소규모 인쇄소(5인 미만) / 인쇄소(5인 이상) / 기타
2. 소상공인에게 1~50개 정도의 소량 제작 문의를 받으신 적이 있나요? — 자주 / 가끔 / 거의 없음
3. 그런 소량 문의를 받으면 보통 어떻게 하시나요? — 진행함 / 수익이 안 맞아 거절함 / 다른 곳을 소개함 / 기타
4. 소량 시제품 제작이 어려운 이유는 무엇인가요? (복수 선택) — 장비가 없음 / 단가가 안 맞음 / 시간이 부족함 / 공정 노하우가 없음 / 기타
5. 소량 제작에 필요한 장비 구성과 상담·가격 기준을 교육받을 수 있다면 관심이 있으신가요? — 매우 관심 / 관심 / 보통 / 관심 없음
6. 교육·협업을 받는다면 어떤 방식이 좋으신가요? — 온라인 강의 / 현장 실습 / 매뉴얼·템플릿 제공 / 협업 네트워크(주문 연결)
