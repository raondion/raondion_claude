## 1. S — 시장 세분화 (Segmentation)

### □ 사용한 세분화 변수

| 변수 | 변수 분류 (B2B) | 구분 | 역할 |
|---|---|---|---|
| 원주·횡성 | 지리적 변수 | — | 나누지 않고 **시장의 범위**로만 씀 |
| 1~3인 운영 | 기업 특성 (규모) | — | 범위로만 씀. 프랜차이즈·중견 제조사 제외 기준 |
| 업종 | 기업 특성 (업종) | 5개 업종 | 세그먼트 이름을 붙이는 단위 |
| **① 인쇄물 성격** | 운영 특성 (용도·요구 사양) | 식품 라벨형 / 매장 소모품형 / 작품 포장형 | **주 변수.** 소재·표시 규정·제작 도구가 같은 업종끼리 묶음 |
| **② 가성비 유형** | 행동 변수 (추구 편익·가격 민감도) | 가격 우선형 / 재고 절감형 / 시간 절약형 / 확신형 | **주 변수 (신규).** 무엇을 "돈값"으로 보는지에 따라 가격 제시 방식과 상품이 달라짐 |
| ③ 사업 단계 | 운영 특성 (고객 역량·준비 상태) | 첫 브랜딩 / 신제품·시즌 | 로고·파일 유무에 따라 서비스 두 갈래로 나눔 |
| ④ 구매 계기 | 구매 상황 변수 | 오픈 / 신제품 / 시즌·명절 / 행사 | 언제 먼저 연락할지 정함. 시즌 분산표의 근거 |
| (참고) 나이대 | 의사결정자 특성 | 20대 / 30대 / 40대 이상 | 가성비 유형이 나이대에 따라 다르게 나타나는 **경향** 확인용 [가설] |

> 구매 주기, 객단가, 지역 규모는 시장을 나누는 변수가 아니라 **2장 타겟팅 평가 기준**으로 씁니다.

### □ 가성비 변수 — 사장님마다 "돈값"의 기준이 다르다

같은 스티커 100장이라도 사장님마다 가성비를 따지는 기준이 다릅니다. 라온디온은 이 기준을 4가지로 나눕니다.

| 가성비 유형 | 사장님의 말 | 가성비 계산법 | 맞는 공급자 | 라온디온 해결 |
|---|---|---|---|---|
| **가격 우선형** | "장당 얼마예요? 제일 싼 데로 할게요" | 장당 단가 | 온라인 인쇄몰 | (직접 공략 안 함) 대량이 필요하면 협력 인쇄소 연결 (E) |
| **재고 절감형** | "많이 사서 버리는 게 더 아까워요" | 쓴 만큼 낸 돈 (남는 재고·폐기 포함) | **라온디온** | **A. 작게 먼저** — 1개부터, 교체형 디자인 |
| **시간 절약형** | "업체 알아보고 설명하는 시간이 아까워요" | 돈 + 내 시간 | **라온디온** | **B. 한 곳에서 한 번에** — 원스톱, 사양 보관 재주문 |
| **확신형** | "돈 들였는데 잘못 만들면 더 손해예요" | 돈 + 실패 위험 (재제작·표시 누락) | **라온디온** | **C. 보고 정한다** — 품목 추천, 실물 샘플, 표시사항 누락 점검 |

- 재고 절감형·시간 절약형·확신형은 P의 문제 ①②③, S의 해결 A·B·C와 그대로 짝이 맞습니다.
- 가격 우선형은 라온디온의 경쟁 상대(온라인 인쇄몰)가 가장 잘 맞추는 고객입니다. 이 고객과 단가로 경쟁하지 않는다는 점을 분명히 합니다.

## 3. P — 포지셔닝 (Positioning)

### □ 가성비를 다시 정의하기 — 장당 단가가 아니라 총비용

소량 제작은 장당 단가로만 보면 대량 주문보다 비쌉니다. 라온디온은 이 점을 숨기지 않고, **사장님이 실제로 쓰는 총비용**으로 비교합니다.

> **총비용 = 제작비 + 남아서 버리는 인쇄물 + 잘못 만들어 다시 만드는 비용 + 업체를 알아보고 설명하는 시간**

| 비교 (예: 시즌 컵 스티커, 실제 사용량 [ ]장) | 온라인 인쇄몰 | 라온디온 인쇄공방 |
|---|---|---|
| 주문 수량 | 최소 [ ]장 | 실제 사용량 [ ]장 |
| 장당 단가 | [ ]원 (낮음) | [ ]원 (높음) |
| 제작비 합계 | [ ]원 | [ ]원 |
| 시즌 후 버리는 수량 | [ ]장 ([ ]원어치) | 0장에 가깝게 |
| 디자인·파일 준비 | 사장님이 직접 또는 별도 의뢰 [ ]원 | 포함 |
| 실물 확인 전 실패 위험 | 있음 | 샘플로 먼저 확인 |
| **실제로 쓴 스티커 1장당 비용** | **[ ]원** | **[ ]원** |

[그림 N] 총비용 비교 막대 — "주문한 장당 단가" vs "실제로 쓴 장당 비용"

> 온라인 인쇄몰 최소 수량·단가는 3곳 이상 비교해 채우고(S 2-3과 같은 자료), 라온디온 단가는 수량 구간 견적표를 씁니다. 시제품 사례 1건을 이 표로 계산해 넣으면 가장 강한 근거가 됩니다.

### □ 포지셔닝 맵

- 가로축: **최소 수량** (대량 ← → 1개부터)
- 세로축: **판단 지원** (파일만 받아 제작 ← → 품목 추천·실물 확인·표시사항 누락 점검)

| 위치 | 공급자 | 가성비 기준 | 설명 |
|---|---|---|---|
| 대량 · 지원 낮음 | 온라인 인쇄몰 | 장당 단가 | 싸지만 완성 파일이 필요하고, 박스·특수 스티커는 최소 수량이 큼 |
| 소량 · 지원 낮음 | 기성 포장재 쇼핑몰 | 구매 금액 | 소량 구매는 되지만 무지 제품이라 브랜드 표현이 안 됨 |
| 대량 · 대면 | 지역 간판·실사 업체 | — | 대형 출력 중심, 소량 소모성 인쇄물은 주력이 아님 [현장 확인] |

### □ 포지셔닝 문장

> **원주·횡성에서 브랜드 인쇄물과 포장을 준비하는 1~3인 식품·매장 사장님 중, 단가보다 "버리는 돈과 실패"를 아끼려는 분에게,**
> **라온디온 인쇄공방은 대량 주문 전에 1개부터 실물로 확인하며 한 곳에서 만들 수 있는 지역 소량 제작 파트너입니다.**
> **장당 단가는 높아도, 남는 재고·재제작·업체 조율 시간까지 합친 총비용은 낮습니다.**

## 4. 비즈니스 모델의 고객 세그먼트 전략

### □ 고객 세그먼트 유형

| 비즈니스 모델 캔버스의 유형 | 라온디온 적용 |
|---|---|
| 대중 시장 (Mass) | ✕ 가격 우선형 고객을 상대하는 온라인 인쇄몰의 영역 |
| **틈새시장 (Niche)** | ○ **원주·횡성 1~3인 소형 사업자 중 총비용을 따지는 고객** — 대량 주문 이전 단계 |
| **세분화 시장 (Segmented)** | ○ 틈새시장 안에서 **인쇄물 성격 3개 유형 × 가성비 3개 유형**별로 대표 구성과 가격 제시 방식을 다르게 |
| 다각화 (Diversified) | △ 3단계 이후 확장 4개 업종 |
| 다면 플랫폼 (Multi-sided) | △ 3단계 이후 타 지역 디자이너·소규모 인쇄소 파트너 (교육·매뉴얼) |

|---|---|---|---|
| 재고 절감형 | 수량 구간 견적표, 총비용 비교표 | B. 제품 스티커 세트 (교체형) | 시즌·메뉴 교체마다 재주문 |
| 시간 절약형 | 사양 카드, "카카오톡 한 줄 재주문" 예시 | A·B 세트 | 두 번째 주문부터 상담 시간이 줄어 마진 상승 |
| 확신형 | 실물 샘플, 품목 추천표, 표시사항 누락 점검 체크리스트 | C. 패키지 포함 테스트 제작 | 샘플 확인 후 본 제작(D), 대량 연결(E) |

| 블록 | ① 빵카페 | ② 농가 가공품 | ③ 소형 카페 | ④ 밀키트·반찬 | ⑤ 공방 |

| 반찬·밀키트 매장 수 | 즉석판매제조가공업 836곳 중 업소명·주소로 반찬·밀키트만 집계 | 2장 지역 규모 |

> 설문은 이미 배포 중이라 문항을 바꾸지 않고, 가성비 질문은 **인터뷰에서 추가로** 묻습니다. 설문 Q6 "가장 어려운 점" 응답도 가성비 유형으로 다시 묶어 볼 수 있습니다 (수량·재고 → 재고 절감형, 업체 여러 곳 → 시간 절약형, 무엇을 만들지·실물 확인 → 확신형, 가격 → 가격 우선형).

## 심사위원 관점 팁

1. **"소량이면 비싸지 않나요?"에 먼저 답하세요.** 심사위원이 가장 먼저 물을 질문입니다. 장당 단가가 높다는 것을 인정하고, 총비용 비교표 한 장으로 "실제로 쓴 1장당 비용은 더 낮다"를 보여주면 약점이 강점이 됩니다.
2. **가격 우선형을 버린다고 쓰세요.** "모든 고객"이 아니라 "총비용을 따지는 고객"으로 좁히면, 온라인 인쇄몰과 단가 경쟁을 하지 않는 이유가 분명해집니다.
3. **"왜 이 고객인가"를 숫자로 답하세요.** 평가표의 ●는 대표 판단이라 약합니다. 설문 결과가 나오면 업종별 이용 의향 %로 바꾸고, 제과점 295곳처럼 확인된 수치는 그대로 강조하세요.
4. **첫 공략 고객은 하나여야 합니다.** "빵카페로 먼저 증명하고 → 같은 도구로 농가·밀키트로 넓힌다"는 순서가 1인 기업의 실행 가능성을 보여줍니다.
5. **시즌 분산표는 1인 운영의 약점을 강점으로 바꾸는 근거입니다.** "주문이 몰리면 어떻게 하나요?"라는 질문에 미리 답하는 자료로 쓰세요.
6. **P·S·3장과 숫자·이름을 맞추세요.** 업종 순위, 진입 상품 이름(A~E), 문제 ①②③ ↔ 해결 A·B·C ↔ 가성비 유형의 짝이 문서마다 같아야 합니다.
7. **가설은 가설로 표시하세요.** 업종 × 가성비 표와 나이대 경향은 가상 페르소나 기반입니다. 인터뷰 2~3건으로 확인되면 그때 사실로 바꾸세요.
