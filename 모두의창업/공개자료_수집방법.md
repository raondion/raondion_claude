# 공개 자료 수집 방법 — 2라운드 사업계획서용

> 2026-10-25 작성. KOSIS 통계표 이름과 소상공인365 메뉴는 이날 직접 확인했습니다.
> 사이트 개편으로 메뉴 이름이 바뀔 수 있으니, 이름이 안 보이면 각 사이트 검색창에 아래 **검색어**를 넣으세요.
> 통계청은 2025년에 **국가데이터처**로 이름이 바뀌었습니다. 출처를 적을 때 "국가데이터처, 기업생멸행정통계(2024)"처럼 씁니다.

---

## 공통 작업 순서

1. 표를 조회해서 **엑셀로 내려받기** (KOSIS는 표 위 '다운로드' 버튼)
2. 필요한 숫자만 뽑아 `모두의창업/자료/` 폴더에 `출처_기준연도.xlsx` 이름으로 저장
3. 화면 **캡처**도 같이 저장 (심사 질의응답 때 근거로 보여줄 수 있음)
4. 사업계획서 그림 아래에 `출처: 기관, 통계명, 기준연도` 한 줄 표기

## ① 원주·횡성의 업종별 사업체 수와 신규 창업 수

### 방법 A — KOSIS: 지역 사업체 수 (전체 규모)

- 사이트: kosis.kr
- 검색어: `시군구별(9개도), 산업별, 규모별, 사업체수 및 종사자수`
- 통계표: **시군구별(9개도), 산업별, 규모별, 사업체수 및 종사자수(성별)** — 고용노동부, 사업체노동실태현황, 2024년
- 조회 설정
  - 시군구: 강원 → **원주시, 횡성군**만 체크
  - 산업: **숙박 및 음식점업**, **도매 및 소매업**, **제조업** (식품·공예 제조가 여기 포함)
  - 규모: 전체 + **1~4인**
- 쓸 숫자 예: "원주시 숙박·음식점업 사업체 ○○개, 그중 1~4인 사업체 ○○%"
- 카페만 따로 보고 싶다면: 검색어 `시 군 구별/산업소분류별 총괄` (경제총조사, 2020년) → 산업소분류 **비알코올 음료점업**(카페)을 고르면 됩니다. 다만 2020년 자료라 오래된 숫자인 점을 표기하세요.

### 방법 B — KOSIS: 지역 신규 창업 수

- 검색어: `시군구별 산업대분류별 기업 수`
- 통계표: **시군구별 산업대분류별 기업 수(활동/신생/소멸)** — 국가데이터처, 기업생멸행정통계, 2016~2025
- 조회 설정: 강원 원주시·횡성군 / 산업: 숙박 및 음식점업, 도매 및 소매업, 제조업 / 항목: **신생**, **소멸** / 최근 5년
- 쓸 숫자 예: "원주시에서는 해마다 숙박·음식점업 신생기업이 ○○개 생기고 ○○개가 사라진다"
- **그래프 추천**: 연도별 신생·소멸 막대그래프 → "매년 새로 시작하는 사장님이 이만큼 있다(잠재 고객)"

### 방법 C — 인허가 데이터: 원주에서 최근 문을 연 가게 수 (가장 지역 밀착형)

카페·디저트·밀키트 가게는 문을 열 때 구청·시청에 영업 신고를 합니다. 이 신고 목록이 공개되어 있어서 **"원주에서 최근 3년간 새로 문을 연 카페 수"**처럼 아주 구체적인 숫자를 만들 수 있습니다.

- 사이트: 공공데이터포털 data.go.kr (2026년 1월부터 지방행정 인허가데이터가 이곳으로 통합되었습니다)
- 검색어: `휴게음식점`, `제과점영업`, `즉석판매제조가공업`, `통신판매업`
  - 휴게음식점 → 카페
  - 제과점영업 → 베이커리·디저트
  - 즉석판매제조가공업 → 수제청, 디저트, 반찬·밀키트
  - 통신판매업 → 온라인 셀러
- 방법
  1. 전국 파일(CSV)을 내려받아 엑셀로 열기
  2. 소재지 주소 열에서 **'원주시'**, **'횡성군'**으로 필터
  3. 인허가일자(개업일) 열을 연도별로 세기 → 2023/2024/2025년 개업 수
  4. 영업상태 열로 **현재 영업 중** / **폐업** 수도 세기
- 쓸 숫자 예: "2025년 한 해 원주시에서 새로 신고한 휴게음식점 ○○곳, 제과점 ○○곳"
- 주의: 파일이 크면 엑셀이 느릴 수 있습니다. 필요하면 파일을 주시면 제가 원주·횡성만 걸러서 집계해 드리겠습니다.

## ② 창업 1~3년 차 생존율

- 사이트: kosis.kr
- 검색어: `산업별 신생기업 생존율`
- 통계표: **산업별 신생기업 생존율** — 국가데이터처, 기업생멸행정통계, 2012~2024
- 조회 설정: 산업 **전체**, **숙박 및 음식점업**, **도매 및 소매업** / 항목 **1년, 2년, 3년, 5년 생존율** / 가장 최근 연도
- 함께 보면 좋은 표: **대표자 성·연령별 신생기업 생존율** (청년 창업자 생존율 비교용)
- 지역(원주) 단위 생존율 표는 없습니다. 전국 수치를 쓰고 "전국 기준"이라고 표기하세요.
- 참고 보도: 2022년 기준 신생기업 1년 생존율 64.1%, 5년 생존율 34.3% — 반드시 KOSIS 최신 표로 다시 확인해서 쓰세요.
- **그래프 추천**: 1년→2년→3년→5년 생존율이 내려가는 선그래프 + 한 줄 메시지
  "처음 1~3년이 고비 → 첫 투자를 작게, 검증 후 키우는 방식이 필요"

## ③ 소상공인의 경영 애로 사항

- 사이트: kosis.kr
- 검색어: `사업체운영 애로사항`
- 통계표: **시도/산업중분류별/사업체운영 애로사항별 기업체수(복수응답)** — 중소벤처기업부, 소상공인실태조사, 2023~2024
- 조회 설정: 시도 **강원**과 **전국** / 산업중분류 **음식점 및 주점업**, **소매업**, **식료품 제조업** / 애로사항 전체
- 엑셀로 받은 뒤 애로사항별 **비율(%)**로 바꿔서 순위 막대그래프로 만듭니다.
- 쓸 문장 예: "강원 소상공인이 꼽은 운영 애로 1위는 ○○, 2위는 ○○" → 비용·판로 관련 항목을 우리 서비스(첫 비용과 재고 부담을 줄임)와 연결
- 우리 설문 6번(가장 어려운 점)과 나란히 놓으면 "공식 통계와 현장 설문이 같은 이야기를 한다"는 그림이 됩니다.

## ④ 지역 상권의 카페·디저트 점포 수 변화

- 사이트: 소상공인365 bigdata.sbiz.or.kr (회원가입·로그인하면 상세 메뉴를 쓸 수 있습니다)
- 메뉴 위치 (2026-10-25 확인)
  - **빅데이터 상권분석 → 업종분석**: 원주시 + 업종(커피전문점, 제과점 등) 선택 → 업소 수 추이
  - **빅데이터 상권분석 → 경쟁분석 / 상권현황**: 원주 주요 상권(혁신도시, 기업도시, 단계동 등)의 업종별 점포 현황
  - **빅데이터 상권분석 → 창업기상도**: 업종별 창업 과밀·적정 정도
  - **소상공인 대시보드 → 업소 통계**: 지역별·업종별 업소 수
  - **상권·시장 트렌드 → SNS 분석**: 키워드 언급량·연관어
- 해볼 만한 것: 첫 화면 검색창에 `원주 카페`를 넣으면 SNS 연관어가 나옵니다. 25일에 확인했을 때 **디저트, 케이크, 브런치, 혁신도시, 꽃집** 등이 상위에 있었습니다.
  → "원주 카페 고객은 디저트·케이크 같은 포장 상품에 관심이 많다"는 근거 이미지로 쓸 수 있습니다. (화면 캡처 + 확인 날짜 표기)
- **그래프 추천**: 원주 커피전문점·제과점 업소 수 3년 추이 선그래프

## ⑤ 기존 인쇄 서비스의 최소 주문 수량과 가격

### 비교할 곳

- 대형 온라인 인쇄몰 2곳 (예: 레드프린팅, 성원애드피아 등)
- 소량 특화 온라인 인쇄몰 1곳 (예: 오프린트미, 비즈하우스 등)
- 패키지 박스 전문 제작 업체 1~2곳 (검색어: `소량 박스 제작`, `인쇄 박스 주문제작`)

### 비교할 품목 (중요)

명함이나 스티커는 이미 소량 주문을 받는 온라인 인쇄몰이 많아서 차이가 잘 드러나지 않습니다.
차이가 큰 품목을 고르세요.

| 비교 품목 | 확인할 것 |
|---|---|
| **인쇄 패키지 박스** (예: 15×15×10cm 단상자) | 최소 수량, 가격, 칼선·도면을 직접 준비해야 하는지 |
| **로고 인쇄 쇼핑백** | 최소 수량, 제작 기간 |
| **모양 칼선 스티커** (원형이 아닌 로고 모양) | 칼선 파일 필요 여부, 최소 수량 |
| **헤더택·띠지** | 최소 수량 |
| **시제품(샘플) 제작** | 샘플 1개만 받아볼 수 있는지, 샘플 비용 |

### 조사 방법

1. 각 사이트에서 같은 조건(크기·재질·수량)으로 **가격 계산기 화면 캡처** — 캡처 날짜를 파일 이름에 넣기
2. 아래 표를 채우기

| 구분 | A 인쇄몰 | B 인쇄몰 | C 박스 업체 | 라온디온 |
|---|---|---|---|---|
| 박스 최소 수량 | | | | 1개 |
| 쇼핑백 최소 수량 | | | | |
| 칼선 파일 준비 | 고객이 직접 | | | 라온디온이 제작 |
| 디자인 상담 | | | | 대면·카톡 |
| 시제품 확인 | | | | 가능 |
| 연락해야 할 업체 수 | 품목별로 따로 | | | 1곳 |

3. 메시지는 "남들은 비싸다"가 아니라 **"품목마다 업체가 다르고, 박스·쇼핑백은 최소 수량이 크며, 칼선·구조는 고객이 준비해야 한다"**로 잡습니다. 1라운드 지원서의 "여러 업체를 컨택해야 하는 번거로움"과 바로 연결됩니다.

- 주의: 특정 업체를 깎아내리는 표현은 피하고, 업체 이름 대신 "대형 온라인 인쇄몰 A"처럼 익명으로 쓰는 것이 안전합니다.
